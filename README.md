# Garatujas

Garatujas são os primeiros desenhos e rabiscos feitos pelas crianças, normalmente entre 0 e 6 anos. Elas representam uma fase importante do desenvolvimento infantil, ajudando na coordenação motora, criatividade e expressão de sentimentos. Com o tempo, esses traços evoluem e passam a representar ideias, emoções e a forma como a criança enxerga o mundo.

# HTML

HTML é uma linguagem de marcação utilizada para estruturar conteúdos na web. Seu principal objetivo é organizar e apresentar informações de maneira acessível para todos os usuários. Por isso, é importante desenvolver páginas pensando em acessibilidade, permitindo que pessoas com deficiência visual, mobilidade reduzida ou que utilizam leitores de tela consigam acessar o conteúdo sem dificuldades.

# TypeScript

## Programação Orientada a Objetos (POO)

A Programação Orientada a Objetos é um paradigma inspirado em elementos do mundo real. Ela ajuda a organizar o código em partes reutilizáveis, facilitando o desenvolvimento, a manutenção e a expansão de sistemas.

## Programação Estruturada vs POO

A programação estruturada é baseada em funções e procedimentos usados para manipular dados. Já a Programação Orientada a Objetos trabalha com objetos que reúnem atributos e métodos em uma mesma estrutura, tornando o código mais organizado e reutilizável.

## Classe e Objeto

Classe é um modelo que define características e comportamentos de um objeto, servindo como base para sua criação.

Objeto é uma instância da classe. Ele possui os atributos e métodos definidos pela classe, mas cada objeto pode armazenar valores diferentes.

## This

O `this` é utilizado dentro de classes para representar o objeto atual. Ele permite acessar atributos e métodos da própria instância que está sendo manipulada.

## Construtor

O construtor é um método especial executado automaticamente quando um objeto é criado. Sua função é inicializar atributos e definir o estado inicial do objeto. Em TypeScript, ele é declarado com a palavra `constructor`.

## Encapsulamento

Encapsulamento é o princípio responsável por proteger e organizar os dados de uma classe. Ele oculta detalhes internos e permite acesso apenas ao que for necessário. Isso é feito utilizando modificadores de acesso como `private`, `protected` e `public`.
